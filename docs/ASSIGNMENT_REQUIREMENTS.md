# 作业要求清单

**来源：** [`sources/Group Assignment0914.docx`](../sources/Group%20Assignment0914.docx)。本文件是对原始作业的整理；遇到歧义以原件为准。此前“合约设计”对话的分析可供理解，但不替代原件。

## 目标与边界

- 以广州期货交易所（GFEX）为场景，设计一份碳期货合约，并写成合约设计文档。
- 每组不超过 5 人。
- 作业允许改选电力期货、天气衍生品等其他产品，但必须清楚解释选题理由。当前默认按题目主线研究碳期货；是否改题尚无决定。
- 任务段落写“不超过 2,000 words 或 5 pages”；提交与格式段落进一步写正文不超过 2,000 words，参考文献和合约表不计入。为避免歧义，最终稿宜同时满足正文 2,000 words 和全文 5 页两个上限，并在提交前核对。

## 报告必须覆盖

1. **标的资产与交易品种：** 在 CEA（全国碳排放配额）和 CCER（国家核证自愿减排量）之间明确选择；论证同质性、价格波动特征、市场潜力。根据中国碳市场特点确定交易单位。作业给出 EU 碳期货一手 1,000 EUA 的对照示例，不能据此直接认定中国合约应相同。
2. **核心合约条款：** 用标准化表格列出下表全部字段，并为每个参数写简短设计依据。作业中的 ±6% 是涨跌停板的举例，不是指定数值。
3. **交割与参考价格：** 解释选实物交割还是现金交割，考虑全国碳排放权注册登记系统的技术条件；说明结算价格的确定方法。EU 的实物交割做法是参考案例，不能直接视为中国方案。
4. **风险管理：** 包括保证金、涨跌停板、持仓限额、大户报告等，并回应履约周期引起的季节性波动。

| 合约表必填字段（原件英文） | 中文理解 |
| --- | --- |
| Trading product and code | 交易品种及代码 |
| Trading unit | 交易单位 |
| Quotation unit | 报价单位 |
| Minimum price fluctuation | 最小变动价位 |
| Maximum daily price fluctuation limit | 每日价格涨跌停板 |
| Minimum trading margin | 最低交易保证金 |
| Contract months | 合约月份 |
| Last trading day | 最后交易日 |
| Delivery method | 交割方式 |
| Delivery grade/standard | 交割品级或标准 |

表格另需设置“设计内容”和“设计依据”两列。每个数值或规则都要回答选取原因，并尽量以政策、制度、研究或数据支撑。

## 团队与提交

- 至少举行 **3 次正式小组讨论**，每次留简要纪要，记录主要内容与决策过程。
- 每位成员独立完成至少一个核心模块的写作；另交一份明确个人贡献的分工说明。
- 提交合约设计文档 **PDF**，含合约条款表和参考文献清单；参考文献采用 **APA** 格式。
- 中文或英文均可。原件写正文不超过 2,000 words，参考文献与合约表不计入。
- 讨论纪要作为附件；分工说明一并提交。
- 截止时间：**10 月 13 日课前**。原件没有注明年份或具体钟点，提交前需向课程信息核对。
- 优秀报告可能被选作课堂展示：10 分钟报告、5 分钟问答。这是可能的展示安排，不是所有组必交演示文稿。

## 当前仍需确定

- 小组成员、具体分工和三次讨论时间。
- 合约参数、交割方案以及支持它们的证据；标的已于 2026-10-03 由用户明确确定为全国碳排放配额（CEA），不包括地方试点配额和 CCER。
- 截止日期年份、课程对“5 页 / 2,000 words”的最终解释（若可向老师确认）。

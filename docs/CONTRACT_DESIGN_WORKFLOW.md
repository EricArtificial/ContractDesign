# 碳期货合约设计流程（本次作业用）

**性质：** 以下是依据[作业原件](../sources/Group%20Assignment0914.docx)制定的研究与写作流程，不是已经获批或已上市的广期所碳期货规则。每项拟议参数在取值前均标为“待定”。外部资料的用途及局限见[来源地图](../research/contract-design/SOURCE_MAP.md)。

## 0. 锁定任务边界与小组工作

**作业要求：** 以广州期货交易所为场景，原则上设计碳期货；若改做电力期货、天气衍生品等，需解释选题。小组不超过 5 人；每人独立写至少一个核心模块；至少举行 3 次正式讨论并留纪要。

**操作：** 建立“要求—证据—决策—报告位置”核对表。确定成员及实际承担的核心模块，预排三次决策会议：①标的与证据计划，②合约表及交割/定价，③风险、压力测试与定稿。纪要仅在真实会议后记录讨论内容、选择、反对理由和待办；分工说明据实际写作整理。若有 5 位成员，四个核心模块与“每人至少一个模块”如何对应，需在分工中说明并视课程口径确认。

**产出：** 任务矩阵、真实会议纪要、实际分工记录。

## 1. 选择标的：CEA 或 CCER

**作业要求：** 明确选择，并论证同质性、价格波动、市场潜力及交易单位。

**研究步骤：**

1. 查现行法规，分别列出 CEA、CCER 的权利单位、登记账户、可交易主体、清缴/注销规则、可用批次或年度及可能的限制。特别区分“可持有”“可交易”“可交割”三种状态。
2. 以相同观察期、相同交易口径比较成交天数、成交量、成交额、价格连续性、交易集中度与履约用途；没有同口径数据就标缺口，不凭年度总量推断逐日流动性。
3. 对候选标的分别写出套保需求方、现货供应方、标准化程度、交割资格和关键制度风险。CCER 如拟使用多种项目/批次，应明确是否同质、是否需要排除或折价；CEA 如涉及不同年度配额，应核对其互换和履约规则。
4. 用同一套定性标准选择一个标的；若关键证据不足，标注待核实并说明为什么暂选该方案。

**方法依据：** 期货合约能否吸引使用者与标的现货市场规模、波动和交易需求有关；合约条款还需与现货商业习惯相容。Bank of England 关于 LIFFE 合约创新的研究发现，合约成功与标的市场规模、波动有关；这只能作为设计分析框架，不能证明 CEA 或 CCER 必然成功。见来源地图 S8、S9。

**产出：** 一页候选标的比较表及最终选择理由。不得把作业背景中“广期所将上市碳期货”等陈述直接当作当前已核实事实。

## 2. 建立证据与数据底稿

**必取资料：** 生态环境部现行配额和自愿减排法规、登记/交易/结算规则；官方市场报告或交易机构公开的价格与成交数据；广期所现行通用规则和已上市合约；ICE EUA 合约仅作国际对照。按标题、发布机构、发布日期、链接、访问日期、条款、适用范围和版本记录来源。

**数据处理：** 按标的、配额年度或 CCER 项目/批次、交易方式和日期区分数据。计算可复核的价格变动、成交量分布、零成交天数、履约前后差异，并说明样本期、缺失值和异常值。若无可靠日数据，不给出精确波动率或据此编造保证金比例。2025 年生态环境部的年度信息可作市场规模初筛，但 CEA 的全年成交量与 CCER 的累计成交量口径不同，不能直接当成同一时期的流动性比较。官方发展报告指出履约期附近的成交与价格具有阶段性特征，因此需单独检查季节性。见 S4、S5。

**产出：** 可追溯来源表、原始数据清单、计算表和“数据能支持/不能支持”的结论。

## 3. 先设计到期交割与价格，再定其余条款

**两条候选路径均需论证：**

| 路径 | 必须验证的可行性 | 必须写清的规则 |
| --- | --- | --- |
| 实物交割 | 合格碳资产是否可在交割窗口转入指定账户；登记系统与期货结算流程如何衔接；可交割供给是否足够且不会被少数主体控制 | 合格品级/年度或批次、账户与冻结/划转、交割期限、货款和权属转移、失败处理、到期价格 |
| 现金交割 | 是否有公开、连续、有代表性且抗操纵的现货价格序列；授权和数据取得是否可行 | 指数样本范围、交易方式、观察窗口、加权方法、无成交/异常/更正时的备用规则、最终结算价 |

**价格概念分开：** 每日结算价用于逐日盯市；最后交易日的交割结算价或现金最终结算价用于到期履约。原件要求解释“参考价格/结算价格”，因此至少说清数据来源、计算方法、发布时间、异常情形和可复核性。不要把现货收盘价、期货每日结算价与到期最终价格写成同一个概念。

**依据：** CEA 的登记系统记录权属并提供结算服务，CCER 也有独立登记和交易系统；这说明设计必须核查系统接口与操作权限，不能据此宣称期货实物交割已经可实施。CFTC 对实物交割合约强调可交割供给与防操纵，对现金结算强调现货价格序列的可靠、公开和及时；其标准仅作合约设计方法参照，不是中国监管规则。ICE EUA 实物交割及 1,000 EUA/手也仅作对照。见 S1–S3、S7、S10。

**产出：** 交割方式比较表、选定方案的逐步流程图和价格规则草案；对尚无公开证明的系统对接事项标“待核实”。

## 4. 逐项填写标准化合约表

表头沿用原件：**Term | Design Content | Design Basis**。下表给出每项参数的取值程序，不预填数值。

| 原件必填字段 | 定值与验算方法 |
| --- | --- |
| Trading product and code | 标的名称与拟议代码须唯一、清楚；检查与广期所现有代码是否冲突。 |
| Trading unit | 根据典型套保规模、现货交易批量、预计合约价值及交易参与门槛选每手吨数；计算“合约价值＝参考价格×每手数量”。 |
| Quotation unit | 明确人民币/吨 CO₂ 或吨 CO₂e 等口径，须与标的法定计量单位、价格源及交割品一致。 |
| Minimum price fluctuation | 比较现货报价精度与期货成交成本；计算“每跳盈亏＝最小变动价位×每手数量”，避免过粗或过细。 |
| Maximum daily price fluctuation limit | 根据历史价格变动、履约期尾部波动和市场连续性设计幅度及基准价格；说明连续涨跌停板后的处理。原件 ±6% 仅为示例。 |
| Minimum trading margin | 用日变动及压力情景覆盖潜在结算风险，结合流动性和履约期风险设基础比例与提高条件；计算“每手最低保证金＝合约价值×比例”。不可只从他品种抄取。 |
| Contract months | 把套保需求与履约节点、价格数据和流动性集中程度对应，说明为何选月度、季度或特定月份，以及挂牌跨度。 |
| Last trading day | 倒排登记划转或指数公布所需时间、节假日和履约期限，明确“合约月份第几个交易日”等可执行表达。 |
| Delivery method | 与第 3 步选择完全一致；若实物，写资产划转；若现金，写价差结算。 |
| Delivery grade/standard | 明确合格资产的登记状态、年度/批次、用途与排除条件；现金交割也要定义价格指数对应的合格标的范围。 |

广期所现有品种合约可提供表格格式和交易所制度参照，但其交易单位、涨跌停板、保证金、交割日不能直接复制到碳期货。参见[现有合约资料索引](../research/gfex-futures/INDEX.md)。

**产出：** 十项均有拟议取值、单位、设计依据和来源的合约表；将每个取值与正文交叉核对。

## 5. 写完整的风险管理机制

至少覆盖原件指定的四项：①基础、临近到期及异常波动时的保证金；②涨跌停板与连续触板处置；③一般月份与临近交割月份的持仓限额；④大户报告的触发条件、报告内容与审核。可补充强行平仓、交易限额、价格异常处置和交割违约处理，但须与广期所规则及所选交割方式相容。广期所通用结算规则实行保证金和逐日盯市；CME 的风险模型说明保证金评估需兼顾历史波动、流动性、季节性和预期事件。这是方法参考，不意味着本作业必须使用 CME 的 99% 标准。见 S6、S11。

**履约周期专门处理：** 根据真实履约安排及数据，评估临近清缴期的现货需求集中、可交割余额下降、价格跳跃和持仓集中。说明何时调高保证金、收紧限仓或提前移仓，并检验是否妨碍正常套保；不能只写“注意季节性”。

**产出：** 风险—触发条件—措施—依据四列表。

## 6. 做一致性和压力测试

至少检查六种情景：①现货价格单日大幅变化；②履约期现货成交与可交割量骤降；③同一主体持仓集中；④登记或价格源停机；⑤无成交、异常成交或价格更正；⑥政策改变合格资产范围。逐项检验价格规则、保证金、涨跌停板、限仓与备用程序是否仍可执行，并明确哪些结果只能做定性判断。

**跨条款验算：** 每跳盈亏与合约价值合理；保证金和涨跌停板的风险覆盖关系有解释；合约月份、最后交易日和交割窗口相容；交割品级与现货价格源相同；实际可交割供给与到期持仓约束相容。CFTC 的合约审查思路强调交割收敛与防操纵，作为这里的检查框架。见 S7、S10。

**产出：** 参数测试表及修改记录；没数据的判断明确写“待核实”。

## 7. 写报告、留存小组材料并验收 PDF

**建议正文顺序：** 标的及选择理由 → 标准化合约表 → 交割与每日/最终结算价格 → 风险管理 → 简短结论。把详尽计算表放研究底稿，正文保留最关键的证据和理由。参考文献按 APA 列出实际使用的来源；逐条检查文中引用与文末条目一致。

**原件要求：** 合约设计文档为 PDF，含合约表及参考文献；正文不超过 2,000 words，参考文献与合约表不计入字数。任务段另写“2,000 words 或 5 pages”，但没有解释页数范围和中文计数方式；稳妥方案是正文控制在字数内且报告本体尽量不超过 5 页，并在提交前核对课程口径。三次真实讨论纪要作为附件，分工说明一并提交。截止时间原文仅为“10 月 13 日课前”，年份及钟点待核对。只有被选中的优秀报告才进行 10 分钟报告、5 分钟问答。

**最终验收：** 四模块完整；十项条款及依据齐全；标的、交割、价格与风险参数一致；来源可追溯且现行性已检查；无虚构数据、纪要或贡献；PDF 可打开且表格清晰；字数、页数、APA、附件及提交时间均已核对。
